# ThreatCluster malicious domains

High-confidence malicious domains extracted from clustered, multi-source
security-incident reporting and validated before publication (deterministic
rules plus a nightly output audit; false positives are retired automatically
and the per-indicator evidence is public).

Rolling 30-day window, refreshed continuously. Served in hosts format
(`0.0.0.0 domain`).
